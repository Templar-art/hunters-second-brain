# Coast Life Constructions — Fable 5 Pack

_Pack for [[coast-life-constructions]] — the audit everything traces to: [[clc-profile-audit]]._
_Built by 10x Visuals · Cinematic real estate/construction system_
_Built from real IG profile audit · Benchmarked against @barlowbuilding and @grimmondau_

## The one-line summary
Coast Life today reads as a **tradie mate's account** (roofers commenting, no finished builds, interchangeable captions). This pack moves them toward **@barlowbuilding's positioning** (architecture-led, named projects, design-story captions, warm-neutral editorial grid) without losing the plainspoken Gold Coast identity. **Read `00_profile_audit.md` first** — every other file's decisions come from it.

## First-week action list (do these in order)

1. **Read `00_profile_audit.md` end to end** — it tells you *why* every other file is set up the way it is.
2. **Book a 30-min Coast Life sync** to fill in three things:
   - The `[FILL IN]` proof claims in `brand_voice.md` section 8 (years, homes completed, HIA/MBA, warranty)
   - The named-project register in `brand_voice.md` section 14 (last 3 finished builds + 3 current active builds)
   - The trade partner tag list in `brand_voice.md` section 13 (cabinetry, stone, electrical, etc. — with IG handles)
3. **Load references into `/references/`.** Screenshot Barlow's ZARMA carousel, Barlow's kitchen post with the Taj Mahal stone caption, Grimmond's website hero. These are the visual + voice targets.
4. **Connect Higgsfield MCP + Blotato MCP** in Claude Code. Add Coast Life's Instagram to Blotato. Turn OFF auto-post.
5. **Open Claude Code, attach `master_playbook.md` + `brand_voice.md` + `00_profile_audit.md`**, and run the session opener from `prompt_library.md`. Confirm Claude echoes back the positioning shift (tradie → architect-led).
6. **Produce PIN 2 first** (talking-head with owner, fastest to film) — see `pinned_posts.md`.
7. **Run Prompt 1 (weekly planning) every Monday morning.**

## Weekly rhythm (~15 min per client)

- **Mon 9am:** Run Prompt 1 → get the week's 4-post plan
- **Tue–Sat:** Run Prompt 2/3/4/5 as each post comes due → schedule as draft in Blotato
- **Fri 4pm:** Review all scheduled drafts → approve or edit
- **End of month:** Run Prompt 7 (monthly review) → adjust next month's plan

## Scaling this to more clients (the 10x Visuals onboarding SOP)

This whole folder is the template. To onboard a new client, follow this order — the audit comes FIRST, before any content is made:

1. **Copy** `/coast_life_fable5/` → `/[new_client]/`
2. **Blank out** the client-specific files (`00_profile_audit.md`, `brand_voice.md`, `strategy_guide.md`, `bio.md`, `pinned_posts.md`)
3. **Get 3 handles from the client:**
   - Their IG handle
   - 2–4 competitor / peer handles (same market)
   - 2–4 aspirational handles (accounts they want to look like)
4. **Run the profile audit first** — hand me the handles, I'll produce the equivalent of `00_profile_audit.md` with real data.
5. **Rerun the brand voice interview** (Prompt 1 from the Fable 5 prompt pack) with the new client on Zoom, informed by the audit findings.
6. **Regenerate strategy, bio, and pins** from the new brand voice + audit.
7. `master_playbook.md` and `prompt_library.md` stay the same — those are the 10x Visuals house standards across every client.

**Skip step 4 at your peril.** The audit is what turns Fable 5 from "AI content generator" into "strategic positioning system." It's also what justifies the $500–2,500/month price tag.
