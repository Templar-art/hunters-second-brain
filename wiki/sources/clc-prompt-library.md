
## Prompt 2 — Carousel from a finished project
```
Create a 6-slide Instagram carousel for Coast Life Constructions.
Project: [PROJECT NAME + SUBURB]
Pillar: [project showcase / educational / process]
Attached: /references/[filename] — match this grade and framing.

Requirements:
- 4:3 aspect ratio
- Slide 1 = hook, slides 2–5 = value, slide 6 = soft CTA
- Use Higgsfield MCP with Nano Banana Pro for any generated visuals
- Text overlays: serif for headings, sans-serif for body, minimal
- Caption in Coast Life voice — first line must earn the tap
- Exactly 5 hashtags (2 local, 2 category, 1 brand)
- Draft in Blotato scheduled for Thu 6:30pm AEST — DO NOT POST
```

## Prompt 6 — Talking-head Reel script
```
Write a 60–90 second talking-head Reel script for the Coast Life owner.
Topic: [e.g. "Why we won't use MDF joinery on a custom build"]

Requirements:
- First line = hook that stops the scroll
- Plain-spoken Aussie voice per brand_voice.md
- 3 clear points with a concrete example each
- End on a strong single-sentence takeaway (not a CTA)
- Include suggested B-roll shot list (5–8 shots) with why each is needed
- Format for teleprompter: short lines, natural breath breaks
```

## Higgsfield MCP visual prompt template (paste inside any generation call)
```
Style: cinematic real estate, 10x Visuals grade.
Grade: clean, bright, natural, neutral. Warm neutrals. No teal/orange.
Framing: [symmetrical hero / one-point perspective / low-angle exterior golden hour]
Lens equivalent: [14–24mm for interior wide / 24–70mm for detail]
Motion (if video): locked-off or subtle push-in only. No gimbal shake, no whip pans.
Reference attached — match lighting and mood exactly.
Aspect: 4:3 for feed, 9:16 for Reel.
```
