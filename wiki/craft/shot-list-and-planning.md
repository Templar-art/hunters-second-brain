# Shot List and Planning

Pre-shoot planning for a property or architecture job. Plan the coverage before you arrive; on-site is for shooting, not deciding.

## The brief
Nail down before booking:
- End use — listing, builder portfolio, architect submission, editorial, socials. Drives everything.
- Hero angles — the 1–2 images that carry the job.
- Must-have rooms/features — what the client is paying to show.
- Brand/style reference — bright agent look vs moody editorial. Get an example.
- Deliverable count — how many final images, plus any 9:16 crops or video.
- Job tier — sets scope. See [[real-estate-vs-architectural]].
- Confirm scope, price, turnaround at booking. See [[client-onboarding]], [[pricing-and-packaging]].

## Site recce / prep
- Orientation + sun check in PhotoPills. Know which facade faces where and when it's lit. Time the shoot by facade, not by convenience. See [[light-and-timing]].
- Access — keys, lockbox code, on-site contact and number, arrival time.
- Who's on site — agent, owner, tradies, stylist. Pets to manage. Parking.
- Weather forecast + backup date for exterior/aerial.
- Photo scout if high-value: walk it, note problem rooms, tight spaces, reflections.

## Standard coverage checklist
Baseline property set (scale up/down by tier):
- Exterior hero — front, plus rear/alfresco.
- Street approach / establishing.
- Every main room — 1–2 angles each.
- Kitchen — wide + one detail.
- Bathrooms — main + ensuite.
- Bedrooms — master emphasised.
- Living / dining, flow shots.
- Features — fireplace, view, staircase, joinery.
- Outdoor — yard, pool, deck, alfresco.
- Aerial — overhead + elevated obliques (see drone rules in [[releases-and-permissions]]).
- Detail / lifestyle — texture, styling vignettes. See [[architectural-details]].

Volume RE: fast, standard angles. Architectural/editorial: fewer frames, planned verticals, detail + abstract coverage.

## Styling set before arrival
Client preps the space — send the declutter checklist ahead. Confirm WHO stages: agent, owner, or paid stylist. See [[interior-photography]] and [[staging-rules]]. Arrive to a shoot-ready home; don't burn paid time tidying.

## Gear checklist
- Bodies + backup.
- Wide zoom + tilt-shift ([[tilt-shift-technique]]).
- Sturdy tripod + geared/level head.
- Flash/speedlight + trigger for interiors.
- Drone + spare props.
- Spare batteries + formatted cards (dual-slot backup).
- Bubble level / in-camera level. Lens cloth. Step stool.
- See [[photo-gear-and-settings]].

## Timing plan
Sequence by light and room shade:
- Shoot each facade in its window; front at its lit hour.
- Interiors in soft/even light; darker rooms when ambient balances.
- Aerial at golden hour or high sun per look.
- Twilight/dusk hero last if selling premium.
- Leave buffer for cloud/wind on exterior + drone.

## Tethered shooting
High-end/architect jobs: shoot to laptop or iPad via Capture One or Lightroom tether. Client/architect reviews composition and verticals live on set. Fewer reshoots, sign-off before you leave, looks professional.

## Comms and turnaround
- Confirm the day before.
- Set turnaround in writing (e.g. RE next-day, architectural 1–2 weeks).
- Agree revision rounds and delivery method up front. See [[deliverables-and-export]].
