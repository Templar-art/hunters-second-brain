# Deliverables and Export

Delivering final files to clients. Export from one master edit; resize and sharpen per output. Never deliver the working file.

## Web vs print
**Web / screen:**
- sRGB colour space.
- JPEG, quality ~80–90.
- Sized for the actual use (portal, socials, web page).
- Screen output sharpening.

**Print:**
- Full resolution.
- Adobe RGB or ProPhoto only if the printer requests it; else sRGB is safest.
- 300 dpi.
- Print output sharpening (stronger than screen).
- TIFF if the printer wants lossless; else high-quality JPEG.

## Real-estate portal specs
realestate.com.au / Domain want large landscape JPEGs, sRGB.
- Generous resolution — long edge ~2000–3000px+.
- Correct aspect (portals crop; deliver landscape).
- Stay under file-size caps.
- **VERIFY CURRENT PORTAL SPECS — they change. Check the portal's current media guidelines before delivering.**

## Consistency
One grade across the whole set — matched white balance, exposure, colour. A set that shifts room to room looks amateur. See [[color-grading]] and the [[photo-editing-pipeline]].

## File naming
Name so agents/builders can sort:
- Address or job code prefix.
- Room order / sequence number (`123-Smith-St_01_front`, `_02_kitchen`).
- Consistent across the job.

## Delivery method
- Online gallery (Pixieset/Pic-Time), Drive, or WeTransfer.
- Download-ready, zipped by set.
- Note any expiry; warn the client to download.
- Gallery doubles as proofing and a soft upsell.

## Multiple output sets
Deliver what the use needs, each exported separately from the master:
- Web set (portal-sized sRGB JPEG).
- Full-res print set.
- 9:16 crops for social/reels. See [[content-systems]].

## Turnaround + archive
- State turnaround at booking; deliver on time.
- Keep the master edit + selects archived after delivery. See [[archiving-and-backup]].

## Licensing / usage
Tell the client what they can do with the images (marketing this listing, portfolio, ads). Set usage in the agreement; extra use = extra licence. See [[releases-and-permissions]].
