# AI Video Tools (property/social)

AI video generation for property and social content. Money gate applies — no credit spend without Hunter's go-ahead ([[higgsfield-pipelines]]).

## Categories & leading tools
Judge by capability/role, not fixed rankings — this space moves fast.
- **Image-to-video** — animate a still (render or photo) into a short clip. Best for property: start from a locked hero frame. Tools: Runway Gen-family, Kling, Google Veo, Higgsfield video, Luma.
- **Text-to-video** — generate a clip from a prompt alone. Less control over exact space; use for abstract/ambient B-roll, not for depicting a real listing.
- **Motion control / camera moves** — some tools expose explicit push/orbit/pan controls; pair with [[cinematic-movement]] language.

## 10x use cases
- **Subtle motion on a still hero render** — gentle drift/parallax to bring a static frame alive.
- **Cinematic establishing pushes** — slow dolly-in on an exterior or hero interior.
- **Social hooks** — a punchy 2–4s motion beat to open a reel.
- **Ambient loops** — water, foliage, light shift for looping backgrounds.

## Limits
- **Short clips** — typically a few seconds; plan to cut, not to run long takes.
- **Temporal artifacts** — warping, morphing, flicker; more likely on complex/detailed scenes.
- **Fidelity risk** — avoid on real client photos where accuracy matters; the space can invent detail. Prefer generating from renders, same as image work.

## Workflow
1. Route: is a real move on set possible? If yes, shoot it. Generate only when it isn't.
2. Get the money gate go-ahead before spending credits.
3. Generate **short** from a strong start frame (image-to-video off a locked render).
4. Cut the clip into the edit → [[video-edit-pipeline]].
5. Stabilise / upscale as needed to clean artifacts and match resolution.
