# Posting Cadence

The system for planning and shipping content consistently. Consistency beats spikes.

## Content pillars
Rotate a fixed set so the feed stays varied and intentional. Rough mix:
- **Showcase** — the finished work, hero reels/stills (~40%).
- **Process / BTS** — build progression, on-site, how we shoot (~20%).
- **Educational** — technique, buyer/builder tips, expertise (~15%).
- **Social proof** — SOLD, testimonials, results (~15%).
- **Lifestyle** — location, Gold Coast, the world around the work (~10%).

Adjust the split per account. Client accounts weight showcase + social proof; own brand carries more educational.

## Batching
- Shoot once, produce many. Capture extra angles/clips knowing they become multiple posts.
- Batch-edit in blocks — one session, several deliverables, one grade.
- Schedule ahead so daily posting is not a daily scramble.

## Realistic cadence
- Quality over volume. 3–5 reels/week is sustainable and enough.
- Consistency beats spikes. Steady beats a burst then silence.
- Never ship a weak post to hit a number.

## Pipeline stages
Idea → shoot → edit → caption → schedule → post → engage.
Track each asset's stage so nothing stalls between shoot and ship.

## Repurpose across formats and accounts
- One asset becomes reel, carousel, still, story.
- Niche accounts feed a master — see the funnel model in [[10x-socials-funnel]].
- Re-cut and re-caption per account's own voice ([[ig-caption-voice]]); never cross-post raw.

## Engagement window
- Reply fast in the first hour after posting. Early engagement drives reach.
- Answer DMs and comments while the post is live.

## Track what works
- Watch saves / shares / watch-time over likes. Those signal reach and intent.
- Find the winners, iterate on the format, retire what flops.
