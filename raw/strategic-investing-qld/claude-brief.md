# Strategic Investing QLD — Claude Design Social Post Brief

## Objective
Create a first batch of 9 polished social posts for **Instagram** and **Facebook** for **Strategic Investing QLD**. The goal is to make the profile look credible, clean, and strategy-led from day one, while appealing to everyday Australians interested in Queensland property investing.

The tone should feel:
- Calm
- Credible
- Professional
- Strategic
- Not hypey
- Not “property guru” style

Use a visual style that feels premium and trustworthy for an older audience, while still modern enough to work on Instagram.

## Brand direction
- Brand name: **Strategic Investing QLD**
- Instagram handle: **@strategicinvesting.qld**
- Core positioning: **QLD property investing made clearer. Education, strategy and support for new and experienced investors.**
- Audience: Everyday Aussies interested in property investing, including beginners and more experienced investors
- Category: **Real Estate Investment Firm**

## Visual direction
Use a premium **navy + gold** brand system.

### Colour direction
- Deep navy as the main base colour
- Warm muted gold as the accent colour
- Off-white / light grey for text
- Optional charcoal or soft beige secondary neutrals

### Design style
- Clean, modern, high-end
- Minimal but not empty
- Editorial / financial-services feel
- Avoid bright teal, neon, purple gradients, or generic “AI-looking” layouts
- Avoid cheesy wealth clichés like sports cars, mansions, or dollar signs
- Avoid overdesigned guru aesthetics

### Typography
Use modern, clean sans-serif typography that feels premium and highly legible.
- Strong headline hierarchy
- Clear subheadings
- Minimal clutter
- Designed to be readable on mobile

### Layout guidance
- Build a cohesive 3x3 Instagram grid
- Mix static quote/text posts with carousels
- Keep margins generous
- Use subtle line work, simple icons, soft overlays, or understated property imagery where useful
- Make each post feel like part of the same system

## Output needed
Create **9 social post designs** with the following for each:
1. Post title / topic
2. Recommended format: static or carousel
3. Suggested visual direction
4. On-image headline text
5. Optional supporting text or slide breakdown
6. Caption draft

These should be designed for Instagram first, but usable on Facebook too.
