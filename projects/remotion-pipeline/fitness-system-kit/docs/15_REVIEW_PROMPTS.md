# Everyday prompts

## New project
Use the existing fitness workflow. Read my approved client rules. Create a brief and source-backed edit plan, then three representative style frames. Do not invent claims or assume every scene needs graphics. State unresolved inputs before rendering.

## Critique
Review this exact render version against the approved brief. Declare what you can actually see/hear. Return blockers and the three highest-value creative fixes with time ranges, evidence and preserve lists. Mark unsupported categories unassessed. Do not praise the code instead of examining the output.

## Targeted revision
At TIME RANGE, change REQUEST. Preserve LIST. Apply only to SCOPE. Re-render affected windows and check regressions. Do not change global style or move unrelated cuts without explaining why and obtaining approval.

## Taste update
Compare my last approved feedback with active preferences. Propose only reusable rules, including client/format scope, exceptions and examples. Do not activate until I approve.

## Benchmark
Use the same source assets, brief and export settings to compare baseline and candidate. Report actual technical results, revision effort and my A/B preference; do not claim audience gains from an aesthetic score.
