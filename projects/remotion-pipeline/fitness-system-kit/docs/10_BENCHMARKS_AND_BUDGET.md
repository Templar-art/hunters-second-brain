# Benchmark and rollout plan

1. Preserve baseline of one real coach education clip; brief/assets fixed.
2. Integrate analysis/caption timing before expanding effects.
3. Approve three style frames, render pilot, review real temporal/audio evidence.
4. Test a narrow revision while preserving the rest.
5. Save approved treatment and candidate taste rules.
6. Expand to noisy gym, exercise explanation, testimonial and offer benchmarks.

Compare identical source inputs with stable delivery settings. Track sample size, difficulty, first-cut approval, substantial revision rounds, recurring failures, time and actual metered cost per approved video. Use human A/B preference; randomise order where practical. Keep held-out examples when enough work exists. Marketing performance needs separate actual campaign measurement.

## Budget
Configure max creative passes=2 initially; per-command timeout; finite retries; approved model/API/render budget. No paid API/cloud upload by default. Read relevant docs/reference cards only. Cache source analysis. Preview low resolution before full export where appropriate. Add agents only when observed failures justify them.

## Rollback
Keep reversible code revision and approved baseline. Shared component changes need regression renders/checks. Write a concise changelog. Never infer improvement just because the code is newer or a model gave itself a higher score.
