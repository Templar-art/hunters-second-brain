# Streetwear Ad Production Pack

Client: [BRAND] (streetwear). Shooter: client on a professional camera. Director/editor: Hunter (10x Visuals).
Output: 4 paid-social ads (9:16 masters, 4:5 + 1:1 crops), 1 hero brand film (16:9 + 9:16), stills from footage.

---

## 1. Camera settings (set once, don't touch)

| Setting | Value |
|---|---|
| Resolution | 4K (UHD) — leaves room to crop 9:16 from 16:9. If the camera can do open gate / 6K, use it |
| Frame rate | 25p for normal (AU). 50p or 100p for slow-mo shots (marked SLO below) |
| Shutter | 1/50 at 25p, 1/100 at 50p, 1/200 at 100p (double the frame rate) |
| Profile | Log (S-Log3 / C-Log / V-Log) if exposing well; otherwise a flat standard profile |
| ISO | Camera's base log ISO (often 800). Night: second native ISO |
| White balance | Manual. 5600K day, 3200–4300K night/neon. Never auto |
| Focus | Face/eye AF for walking shots, manual for details and macros |
| Audio | Scratch audio on (for sync + ASMR cues) |
| Stabiliser | Gimbal for all moving shots; IBIS on for handheld |
| ND filter | Variable ND in daylight to hold shutter at 2× frame rate |

**Framing rule:** everything ends up vertical. Keep the subject in the centre third, headroom tight, no key action at frame edges. Shoot a few true-vertical takes of the hero shots if the rig allows.

## 3. The ads

Each ad: **hook in the first 1 second**, text overlay assumes no sound, logo + CTA at the end card. 9:16 length 10–20s.

### Ad A — "Fit Swap" (transition reel)
Hook: model walks to camera → whip pan → new fit, same stride.
- A1 Wide low-angle walk to camera, fit 1, ends with a whip pan right (24mm, gimbal)
- A2 Same walk, fit 2, starts with a whip pan in from the left (match speed + direction)
- A3–A5 Repeat for fits 3–5
- A6 Final fit: stops, looks into lens, slight head nod (hold 3s)
Overlay: "5 fits. 1 drop." → end card "Shop the drop — [link]"
Tip: lock exposure + white balance so the cuts match. Same marker on the ground every take.

### Ad B — "Made Right" (detail / quality ad)
Hook: extreme close-up of the print, slow push-in.
- B1 Macro of the print / embroidery, slider push-in (SLO 50p)
- B2 Hand runs over fabric, side light for texture (85mm, SLO)
- B3 Heavyweight tee drop: tee falls onto a table (SLO 100p)
- B4 Neck tag + stitching close-up
- B5 Pull-back to model wearing it, laneway (35mm)
Overlay: "[GSM] heavyweight cotton" / "Printed in [city]" / "Built to last" → CTA.
⚠️ Only write fabric claims the client confirms.

### Ad C — "Night Run" (vibe / brand)
Hook: on-camera flash pop on a model's face at night.
- C1 Flash portrait, model to camera, neon behind (35mm, flash on)
- C2 Crew walking a wet street, low angle (16–24mm, gimbal)
- C3 Hood up / jacket thrown on (50mm, SLO)
- C4 Reflection shot in a shop window or car (50mm)
- C5 Crew stopped, all look at camera, push-in (24mm)
Overlay: minimal — brand name + drop date. Music-led.

### Ad D — "Rate the Fit" (UGC-style, cheapest to make)
Hook: "Rate this fit out of 10" text, model spins.
- D1 Model enters frame, full-body spin (35mm, handheld-loose)
- D2 3–4 close-ups: shoes, tee print, cap, chain
- D3 Optional: strangers on the street giving ratings (get verbal + written consent)
Overlay: score cards per piece → "Shop the fit."

### Hero Film (30–60s, 16:9 + 9:16)
Built from all the above plus:
- H1 Rooftop golden hour wide, crew silhouettes
- H2 Process shot: screen print pull / heat press / packing orders
- H3 Skate or movement action (fisheye if skate)
- H4 Flat-lays of each colourway, top-down (for stop-motion)
- H5 Closing hero: single model, slow-mo, looks to lens → logo

## 6. People + paperwork

- **Models:** 2–3, varied looks; send them the fit list + mood board. Signed model release (usage: paid social ads, web, organic, perpetual).
- **Location permits:** council filming permit for public streets if using a crew/gear on footpaths; written OK for rooftops, carparks and businesses.
- **Strangers on camera** (Ad D): written release, or blur.
- **Music:** licensed track (Artlist/Epidemic) or a local artist with written permission. No unlicensed songs on paid ads — Meta will mute or reject them.

## 7. Pre-production checklist

- [ ] Confirm brand name, products, hero pieces for this drop, colourways
- [ ] Mood board (5–10 refs) sent to client + models
- [ ] Fit list: which model wears what, in what order
- [ ] Locations scouted at the right time of day
- [ ] Permits / permissions
- [ ] Model releases signed
- [ ] Garments steamed + bagged per fit
- [ ] Batteries charged, cards formatted, gimbal balanced
- [ ] Weather check (rain backup: warehouse / covered carpark)

## 8. Post / delivery

- Footage handover: copy every card to **2 drives** on set; send Hunter the full card dump (no deletions).
- Hunter edits: colour grade from log, captions, 9:16 master + 4:5 + 1:1 crops.
- Deliverables: Ads A–D (+ 2 hook variants each for testing), hero film, 20–30 graded stills.
- Ad testing: run all 4 concepts at once, keep the best by hook rate + CTR after 3–4 days, cut new hooks for the winner.
