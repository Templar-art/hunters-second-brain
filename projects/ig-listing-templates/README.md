# Harcourts Property Hub — IG listing post templates

Five square (1080x1080) listing posts for Harcourts Property Hub. Full-bleed listing photo, navy scrim, light-blue status chip, address, and the white Harcourts wordmark top right. No 10x branding.

Statuses: Just Listed · Coming Soon · Sold · Sold Off Market · Open Home.

## Where the current version lives

`canvas/` — the live deliverable, published as a design canvas (five artboards on one pan/zoom canvas, with PNG/PDF export).

| File | What it is |
|---|---|
| `canvas/build-artboards.py` | **Edit here.** Generates all five artboards from one spec. |
| `canvas/*.dc.html` | Generated artboards. Don't hand-edit; they'll be overwritten. |
| `canvas/canvas.json` | Canvas layout: artboard positions, sticky note, launch view. |
| `canvas/listing-post-templates.html` | The seeded, publishable canvas. Regenerated by the seeder. |
| `assets/hero-aerial.jpg`, `assets/hero-terrace.jpg` | Demo photos, native 1080x1080 (Stonehaven frames standing in for real listing photography). |
| `assets/harcourts-wordmark.png` | White Harcourts wordmark. `harcourts-icon.png` is the h-icon, unused so far. |

The five artboards share nothing at runtime — that's how Design Components work — so every shared value (colours, scrim, type ramp, margins) is duplicated into each file. It drifted twice when hand-edited, which is why the generator exists. All shared regions are now byte-identical.

## Changing a template

1. Edit `canvas/build-artboards.py` — the spec at the top holds the status text, hero photo and detail line per artboard; the constants above it hold the brand values.
2. `python3 build-artboards.py`
3. Re-seed and publish the canvas (see below).

## Type

Nunito Sans 400/600/700/800, one family, weight-driven hierarchy.

The brief specified **BW Vivant Bold** (headings) and **Circular Std Regular** (body); both are paid fonts with no files on hand, and Nunito Sans is the closest free stand-in — it also matches the wordmark's rounded humanist-geometric flavour. If the real Harcourts font files turn up, swap the `<link>` and the `font-family` in `build-artboards.py` and regenerate.

## Brand values

| Role | Value |
|---|---|
| Light blue (status chip fill) | `#3ba0e8` |
| Dark navy (scrim, chip text) | `#0a1c3e` |
| Type | white / `rgba(255,255,255,0.92)` |

Contrast is measured against the actual composited pixels, not estimated: every text element sits at 5.19:1 or better against the brightest 5% of the background beneath it. Chip text is 5.91:1 on its own fill. If you swap in a brighter photo, the `scrim` tweak on each artboard raises the floor.

## Re-seeding the canvas

The `/design` skill owns this. It seeds a fresh copy of the canvas payload from the working files:

```
seed-canvas.mjs --out listing-post-templates.html \
  --title "Harcourts Property Hub Listing Posts" \
  --artboard Main.dc.html --artboard ComingSoon.dc.html --artboard JustSold.dc.html \
  --artboard SoldOffMarket.dc.html --artboard OpenHome.dc.html \
  --image ../assets/hero-aerial.jpg --image ../assets/hero-terrace.jpg \
  --image ../assets/harcourts-wordmark.png --canvas canvas.json
```

Then publish `listing-post-templates.html` as an artifact (same URL each time).

## Superseded

The loose `*.html` + `styles.css` + `serve.mjs` set in this folder is the **first draft** (Bodoni Moda, tracked kicker, dashed logo placeholder) — rejected, kept only for history. `assets/logo-placeholder.svg` and `preview/` belong to it too. Safe to delete.

## Note on Canva

Originally scoped as Canva Brand Templates. Canva's MCP connector can't create a native 1:1 square, can't reposition elements precisely, and can't tag Autofill fields — all of that needs the Canva web editor by hand. Built as a design canvas instead.
