# 10x Visuals, Prestige rebuild

Static rebuild of `10xvisuals.com.au` against Prestige Design System v1.0, amended for WCAG AA: the homepage plus its five interior pages. Self-contained HTML files sharing one `assets/` folder. Works over `file://` and HTTP.

- **Spec + build outcome:** [2026-07-30-10x-homepage-prestige-rebuild-design.md](../../docs/superpowers/specs/2026-07-30-10x-homepage-prestige-rebuild-design.md)
- **Design system of record:** [DESIGN.md](../../DESIGN.md), the Prestige layer section
- **Wiki:** [[10x-website]]

## Run it

```bash
python3 -m http.server 8791 --directory "projects/10x-site"
```

Then open `http://localhost:8791`. Opening `index.html` directly also works; assets are all relative.

## Before this goes live

1. Set `FORM_ENDPOINT` at the top of the script block to a real POST endpoint. While it is `null` the form opens a `mailto:` compose to hello@10xvisuals.com.au, so enquiries still arrive but nothing is captured server-side.
2. Replace the founders photograph. The current frame is a studio-seamless team shot, greyscaled and cropped as a holding treatment.
3. Decide on the client strip. It is currently a typeset Prata roster of sixteen clients. Logos return only with a matched monochrome set on transparent grounds.
4. **Stonehaven has no project page.** It is the hero and the opening case study, but `10xvisuals.com.au` has no `/stonehaven` route, so that entry is deliberately not a link and carries no "View project" CTA. Build the page, then make it one.

## Assets

Every image ships as **WebP plus a JPEG fallback, at three or four widths**, wired up through `<picture>` with `srcset` and `sizes`. Measured cold-cache transfer: **0.98MB at 1440px, 0.34MB at 390px**, down from 4.34MB when a single full-size JPEG was served to everyone. The hero is preloaded with a responsive `imagesrcset`.

**The full-size masters are not in this folder.** They were removed because an unreferenced 4.34MB would ship with a static deploy. The masters live in `~/Downloads` (the 47 Somerset Drive prints) and on the live WordPress uploads. To regenerate the variant set from a master, per image:

```bash
# widths 800 / 1400 / 1800 / native, WebP from each JPEG
sips -Z 1400 -s format jpeg -s formatOptions 68 master.jpg --out name-1400.jpg
cwebp -quiet -q 72 -m 5 name-1400.jpg -o name-1400.webp
```

`assets/manifest.json` records the widths generated for each image; keep it in step with the `srcset` values in `index.html`.

To re-fetch the client logo files that were removed:

```bash
B=https://10xvisuals.com.au/wp-content/uploads; mkdir -p projects/10x-site/assets/logos; for f in The-Agency-REA Shape-Construction Ray-White-Rea Salisbury-Building-Projects-Logo PRD-Rea Mastr-Logo Kollosche Gold-Coast-BMW-Logo Ashley-Cooper-Construction-Logo; do curl -sfL "$B/2026/03/10x-Visuals-Web-Logos_$f.jpg" -o "projects/10x-site/assets/logos/$f.jpg"; done
```

## Work order

Six entries: Stonehaven (full bleed), Davenport and Bespoke (two up), Elysium (full bleed), then SOL and Broncos Leagues Club (two up). SOL sits below Elysium by request; it used to be the hero.

The hero is Stonehaven at 47 Somerset Drive, marketed by Whitefox: the late-afternoon aerial (`47 Somerset Drive _ Touch Ups Print-3.jpg`), which shows the full acreage, the entry court and the pool terrace. It replaced the SOL drone frame, then briefly a dusk patio frame that Hunter rejected.

**Legibility was measured, not eyeballed.** For each type zone, the photograph's mean luminance in that region is composited through both hero scrims and the type's own alpha, then checked as a contrast ratio. At 1440 and at 390 the kicker, headline and lede all pass. The kicker only passes because it is full `--ivory`; at the DS's `--ivory-soft` it measured 3.45:1 against a 4.5 requirement, since it sits where the scrim is weakest over sunlit grass.

## Scope

All six pages: `index.html` plus `branding.html`, `content-creation.html`, `lead-generation.html`, `systems-processes.html`, `contact-us.html`. The five interior pages are generated by `scripts/build_pages.py`, not hand-written — edit the `PAGES` dict and re-run it rather than editing the HTML directly, or the next regeneration will discard the edit. They share `assets/prestige.css` and `assets/prestige.js` with the homepage, so the menu overlay, scroll cue and magnetic CTAs come for free.

## The project lightbox

Clicking any work plate on the homepage does not navigate immediately: the clicked photo's own `<img>` is measured and animated via `transform` (translate + scale, the FLIP technique) into a fullscreen preview, so the photograph itself visibly grows rather than a generic box fading in over it. The five linked plates keep their real `<a href>` to the live WordPress project pages — a modifier-click (Cmd/Ctrl/Shift, middle-click) bypasses the preview and follows the link immediately. Stonehaven has no destination page, so it is a real `role="button"` trigger with its own keyboard handling, and the preview hides "View full project" for it specifically. Escape closes, clicking the backdrop closes, focus is trapped while open and returned to the trigger on close, and `prefers-reduced-motion` skips the transform animation and shows the frame in place.

## Regenerating the interior pages

```bash
python3 projects/10x-site/scripts/build_pages.py
```

Reads `assets/manifest.json` for image widths and overwrites the five interior HTML files from the `PAGES` dict in the script. The homepage (`index.html`) is not touched by this script.

## Why it does not look generated

The page was reworked specifically against the AI-landing-page tells. What changed and why:

- **The work leads.** It used to sit below three text sections. A media studio burying its work is backwards, and "hidden work" was the one structural fault the UI database flagged too.
- **No repeated marker above headings.** Tracked eyebrows went first; the 56px hairline that replaced them was the same reflex one level down, so it went too. Headings and surface changes carry the cadence now.
- **One typographic statement, not six equal headings.** The studio thesis runs at up to 60px in a left rail; every other heading drops to a label scale. Uniform heading size is texture, not hierarchy.
- **An editorial column pair.** Prose sits in a heading rail plus a wider body column instead of one narrow left column repeated down the page, which was the single strongest templated signal.
- **The client roster is grouped by what each client is** (agencies, builders and developers, venues and brands). Real information, and it stops seventeen names reading as an even filler grid.
- **Uneven vertical rhythm.** Sections use `pad-tight` or `pad-wide` rather than one clamp everywhere.
- **The close is left-aligned**, not a centred landing-page footer.

Rejected from the UI database because it contradicts the brand: Playfair Display (also on the reflex-reject list), `#2563EB`, Brutalism's instant transitions and 700-weight type, and `back.out(1.4)` easing, which is the bounce that DESIGN.md bans outright.
