Website and digital

Logo

Primary 150 px wide minimum, secondary 110 px, icon 32 px. Clear space on every side is the cap height of the O, including inside a header that’s already tight.

Type

Inter 300 to 600 for everything functional, Sinhala MN for display only, never below 18 px. Sinhala MN is Apple‑only, a nominated substitute and CSS fallback are needed before launch (see Open decisions). Measure to about 65 characters.

Colour

No sage carries body copy, at any size or weight. Set text in Basalt, or on Basalt.

Known fix required

The site currently ships Basalt as #2D2D2D. The master artwork is #3A3A3A. Change the token, not the artwork, and re-check any image scrim measured against the old value.

Retired name

oneillgroup.com.au is no longer the name. Remove it from markup, metadata, redirects and artwork wherever it still appears.
