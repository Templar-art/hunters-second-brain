Type

Two families, never a third.
Aa

Sinhala MN — display

Headlines, campaign statements, board addresses. One weight, never below 18 px, otherwise its contrast breaks down. Apple‑only: a restrained high‑contrast serif substitute and a CSS fallback still need to be nominated before launch (see Open decisions).
Aa

Inter — text

Everything that has to work: body copy, navigation, agent details, captions, forms, signage information. Weights 300, 400, 500, 600. Nothing heavier.
